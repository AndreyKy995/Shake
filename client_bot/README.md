# ИИ-менеджер для клиентов (Telegram)

Бот сам переписывается с клиентами от вашего имени, отвечает на типовые вопросы, выясняет, что нужно,
и **присылает вам только тех, кому вы действительно нужны**: с кратким резюме и контактом.

## Как это работает

```
Клиент пишет боту ─► ИИ (Claude) отвечает и решает, кто это:
   💬 dialog      — продолжает выяснять, вас не беспокоит
   🔥 hot         — целевой и готов → карточка вам
   🙋 human       — просит человека / нестандартный вопрос → карточка вам
   🚫 not_target  — вежливо отказывает, вас не беспокоит
   🗑 spam        — игнорирует
```

Карточка клиента у вас в Telegram:
- **ответьте (reply) на карточку** — текст уйдёт клиенту от имени бота, а бот в этом диалоге замолчит;
- кнопка **«✋ Беру диалог»** — бот замолкает, все сообщения клиента идут вам;
- кнопка **«🤖 Вернуть боту»** — бот снова ведёт диалог.

Команды для владельца: `/leads` — последние нужные клиенты, `/stats` — статистика.

## Запуск (15 минут)

1. **Создайте бота:** в Telegram напишите [@BotFather](https://t.me/BotFather) → `/newbot` → получите токен.
2. **Получите ключ Claude API:** [console.anthropic.com](https://console.anthropic.com) → API Keys (нужно пополнить баланс).
3. **Установите:**
   ```bash
   cd client_bot
   python3 -m venv .venv && source .venv/bin/activate
   pip install -r requirements.txt
   cp .env.example .env
   ```
4. Впишите в `.env` токен бота и ключ Claude.
5. **Опишите свой бизнес в `business.md`**: что делаете, цены, кто целевой клиент, что выяснить до передачи вам,
   частые вопросы. Это главное: бот отсеивает клиентов ровно по этим правилам.
6. Запустите `python bot.py`, напишите своему боту `/myid`, вставьте число в `OWNER_CHAT_ID` в `.env`
   и перезапустите бота.
7. Попросите друга написать боту как клиент и проверьте, что карточка приходит вам.

Чтобы бот работал круглосуточно, его нужно запустить на сервере (VPS от ~300 ₽/мес) или на любом хостинге для Python.

## Сколько стоит

По умолчанию используется `claude-opus-5-5` с `CLAUDE_EFFORT=low` (быстрые и недорогие ответы).
Ориентировочно это несколько центов за диалог; точная цена зависит от длины переписки и `business.md`.
Если ответы кажутся поверхностными, поставьте `CLAUDE_EFFORT=medium`.

## Файлы

| Файл | Что внутри |
|---|---|
| `bot.py` | Telegram: клиенты, карточки владельцу, ответы через reply, кнопки |
| `ai.py` | Промпт ИИ-менеджера и разбор его решения (ответ + статус + резюме) |
| `storage.py` | SQLite: клиенты, история переписки, карточки |
| `business.md` | Описание вашего бизнеса — **заполните своим** |

## Другие каналы

Ядро (`ai.py`, `storage.py`) не привязано к Telegram: у каждого клиента есть поле `channel`.
